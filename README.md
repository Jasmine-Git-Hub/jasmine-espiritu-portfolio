# Jasmine Michaela Espiritu — Portfolio

Personal portfolio built with React, TypeScript, Vite, Tailwind CSS, GSAP, Lenis and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Editing content

- Text, projects, certificates, skills: `src/data/portfolio.ts`
- Headshot: `public/images/profile.jpg`
- CV download: `public/cv.pdf`
- Certificate PDFs: `src/assets/`

## Deploy

Hosted on Vercel. Every push to `main` triggers a new deployment.
